 React Project: Modular Architecture Demo

Проект демонстрирует применение модульной архитектуры (Feature-Driven / Feature-Sliced подход) на фронтенде с использованием React, TypeScript и Vite.

🏛️ Что такое модульная архитектура?

Модульная архитектура — это подход к проектированию программного обеспечения, при котором приложение разбивается на независимые, изолированные и слабо связанные между собой функциональные блоки (модули / фичи).

 Основные принципы:
1. Разделение по бизнес-логике (Слабая связанность / Loose Coupling): Компоненты группируются не по техническому типу (`components/`, `hooks/`, `redux/`), а по их функциональному назначению (например: `auth`, `profile`, `payment`).
2. Высокая связность внутри модуля (High Cohesion): Все, что нужно для работы конкретной фичи (компоненты, хуки, типы, API-запросы), лежит внутри папки этого модуля.
3. Public API (`index.ts`): Каждый модуль имеет "контрольно-пропускной пункт" — файл `index.ts`. Из внешнего мира (других модулей) можно импортировать только то, что явно экспортировано из этого файла. Прямые импорты из внутренностей модуля (например, `import ... from 'modules/auth/components/SecretForm'`) строго запрещены.

Структура проекта

* `src/app/` — Настройки приложения, глобальные провайдеры, стили.
* `src/components/` — Общие UI-компоненты (Shared layer). Кнопки, модалки, инпуты без привязки к бизнес-логике.
* `src/modules/` — Слой бизнес-модулей.
  * `auth/` — Модуль авторизации (форма входа, логика сессии).
  * `profile/` — Модуль личного кабинета (карточка пользователя, редактирование данных).

 Как запустить проект локально

1. Клонировать репозиторий:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Запустить сервер для разработки:
   ```bash
   npm run dev
   ```
